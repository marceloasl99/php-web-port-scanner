# PHP Web Port Scanner

A browser-based TCP port scanner built with PHP.

## Features
- Web interface
- Custom IP address
- Custom port range
- Displays open/closed ports
- Educational network diagnostics

## Requirements
- PHP 7.4+
- Web server (Apache/Nginx)

## Usage
Place the project in your web root and open `index.html` (or `index2.html`) in your browser.

## Security
This tool should only be used on systems and networks you own or have explicit authorization to test.
